# O desfecho da urna na lista: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cada linha da lista de candidaturas diz o desfecho da urna (eleita, suplente, não eleita, 2º turno), com um filtro por desfecho e a mesma informação na ficha.

**Architecture:** O desfecho já chega pelo `consulta_cand` do TSE (`Cand.sit_turno`). Um módulo novo `pipeline/desfecho.py` traduz o texto do TSE para um código 0..4; `agregar` carrega o texto no `Agg`; `escrever` põe o código no fim da linha do ranking (UF 17 campos, Brasil 18) e na ficha, e o `meta` diz se algum desfecho existe. O front lê o campo novo, desenha uma pastilha colorida por desfecho (a única exceção à regra "nenhuma cor depende do dado") e ganha o chip de filtro `Desfecho`, com estado `S.desf` e `d=` no endereço.

**Tech Stack:** Python 3, só biblioteca padrão, `unittest`; front em um arquivo `site/index.html`, sem biblioteca.

**Spec:** `docs/superpowers/specs/2026-10-05-desfecho-design.md`

## Global Constraints

- Português do Brasil com acento em todo texto de interface e de mensagem. **Nunca travessão.** `TestHigieneDoFonte` e `TestRedacaoDoSite` reprovam a rodada.
- Nenhuma palavra de `PROIBIDAS` (`pipeline/alarmes/__init__.py`).
- **Nunca grave código por heredoc de shell.** Use a ferramenta de edição.
- Não commite `site/dados/`.
- Linha do ranking: UF passa de 16 para **17** campos, Brasil de 17 para **18**. O campo novo é o último. Na linha do Brasil a UF continua no índice 16.
- Código do desfecho: 0 sem desfecho, 1 eleita, 2 suplente, 3 não eleita, 4 segundo turno.
- Cores da pastilha (claro fundo/fio/tinta; escuro fundo/fio/tinta): eleita `#DDF3E4/#1E7A46/#0F4A2A` e `#123A24/#3FA96A/#BFEBCF`; não eleita `#FBE3E1/#B3261E/#7A1A14` e `#3E1613/#D9534A/#F5C4BF`; suplente e 2º turno `#DCE8F5/#2F5F8F/#1B3A58` e `#14283D/#6FA3D8/#C6DCF2`. Fio de 2 px.
- Rótulos no plural feminino no chip ("Eleitas", "Não eleitas"); no gênero da candidatura na linha e na ficha (campo 13 da linha: 1 é feminino).
- Com `meta.tem_desfecho` falso a tela fica **exatamente** como hoje: nem chip, nem pastilha, nem texto na ficha.
- Testes: `python -m unittest discover -s tests` (demora uns 2 min por causa da rodada ponta a ponta; para um teste só, `python -m unittest tests.test_pipeline.TestDesfecho -v`).
- Commits em português, uma frase, no estilo do `git log`. Terminar com as linhas de atribuição que o ambiente pedir.

"""O desfecho da urna, do texto do TSE para um codigo pequeno.

`DS_SIT_TOT_TURNO` vem do consulta_cand e so e preenchido depois da
totalizacao; ate la e `#NULO` em toda linha. O vocabulario aqui e o historico
do TSE. Texto que ele nao reconhece vira 0 e e marcado como desconhecido, para
sair em meta.desfecho_desconhecidos e ser corrigido na rodada seguinte sem
derrubar o site.
"""
import re
import unicodedata

from .carregar import VAZIO

ELEITA, SUPLENTE, NAO_ELEITA, SEGUNDO_TURNO = 1, 2, 3, 4

# texto normalizado -> codigo
TABELA = {
    'ELEITO': ELEITA,
    'ELEITO POR QP': ELEITA,
    'ELEITO POR MEDIA': ELEITA,
    'SUPLENTE': SUPLENTE,
    'NAO ELEITO': NAO_ELEITA,
    '2O TURNO': SEGUNDO_TURNO,
    '2 TURNO': SEGUNDO_TURNO,
    'SEGUNDO TURNO': SEGUNDO_TURNO,
}


def normaliza(texto):
    """Caixa alta, sem acento, um espaco so; vazio para marcador de vazio."""
    s = (texto or '').strip()
    if s in VAZIO:
        return ''
    # o ordinal masculino e o simbolo de grau viram 'O' antes de tirar acento,
    # para '2º TURNO' e '2° TURNO' cairem na mesma chave
    s = s.replace('º', 'O').replace('°', 'O')
    s = unicodedata.normalize('NFKD', s)
    s = ''.join(c for c in s if not unicodedata.combining(c))
    return re.sub(r'\s+', ' ', s).upper()


def codigo(texto):
    return TABELA.get(normaliza(texto), 0)


def desconhecido(texto):
    """Texto nao vazio que a tabela nao reconhece."""
    n = normaliza(texto)
    return bool(n) and n not in TABELA
```

def desfecho_em(estado, hoje, tem):
    """O dia em que o desfecho da urna apareceu pela primeira vez, ou ''.

    A ficha cita essa data como "TSE, dd/mm/aaaa". Ela e gravada uma vez e nao
    anda com as rodadas seguintes, senao a mesma informacao mudaria de data
    todo dia.
    """
    caminho = _p(estado, 'desfecho-em.txt')
    if os.path.exists(caminho):
        with open(caminho, encoding='utf-8') as f:
            dia = f.read().strip()
        if dia:
            return dia
    if not tem:
        return ''
    os.makedirs(estado, exist_ok=True)
    with open(caminho, 'w', encoding='utf-8') as f:
        f.write(hoje + '\n')
    return hoje
```
