# contas2026

Painel de gastos de campanha das eleicoes de 2026, a partir da prestacao de contas do TSE.

Estado: M0, o spike que decide se o GitHub Actions consegue baixar do CDN do TSE.

Fonte dos dados: TSE, dados abertos, conjunto "Prestacao de Contas Eleitorais - 2026".
Sinais automaticos nao sao conclusao sobre ninguem.
